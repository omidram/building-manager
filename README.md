# همسایه — سیستم مدیریت ساختمان مسکونی

پلتفرم یکپارچه برای مدیریت اعضای ساختمان، اعلان‌ها، رأی‌گیری، شارژ ماهانه، هزینه‌ها، نظافت و تیکت‌گذاری.

## اجرا

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

سپس باز کنید: [http://localhost:3000](http://localhost:3000)

## حساب‌های آزمایشی

| نقش | ایمیل | رمز |
|------|--------|------|
| مدیر | `manager@hamsaye.local` | `123456` |
| ساکن | `ali@hamsaye.local` | `123456` |

## امکانات

- لندینگ مینیمال با تصویرسازی وکتور
- داشبورد RTL فارسی
- اعلانات همگانی (ارسال توسط مدیر)
- مدیریت اعضا
- قوانین ساختمان
- رأی‌گیری با نمودار نتیجه
- شارژ ماهانه و ثبت پرداخت
- ریز هزینه‌های ماهانه
- برنامه نظافت
- تیکت و گفتگو بین ساکن و مدیریت

## استک

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma + SQLite
- احراز هویت مبتنی بر کوکی امضاشده
- Framer Motion / Lucide (آیکون‌ها)
